## 数据范围与结论

GSC Web、country=jpn、dataState=final。当前2026-09-02—09-29，对比2026-08-05—09-01，均28天。数据取得时间10/4，最终数据尚未覆盖10/1及10/4的新发布。

- 独立站点汇总：4,338点击、127,225曝光、CTR3.41%、均位7.15；前期1,359点击、38,758曝光、CTR3.51%、均位8.44。28天增长与最近一周下降可以同时成立，不据此否定用户的近期回落反馈。
- 当前可见查询1,513条；可见查询合计2,499点击、92,471曝光，小于独立总量。匿名查询和聚合差异使其不能代替站点总数，也不能据此给出完整市场份额。
- 初筛19个互斥意图组，90条曝光≥130、均位4—20的候选查询；其中21条有两个以上页面达到复核阈值（各≥30曝光且≥该查询曝光15%）。这是检查队列，**不是21起已确认内耗**。
- [意图汇总](clusters.csv)与[关键词候选清单](opportunities.csv)是加工后的运营表。自动推荐的owner只是初筛：解法类必须再落到具体手筋/难度页，变体必须落到对应玩法。不能对整类词机械改链接或canonical。
- 原始API响应仅保留在临时目录，不进入仓库。脚本`report-seo-opportunities.py`只加工用户环境中的只读导出，不联网、不接触凭据、不提交索引。

## 页面分工

- 首页：通用“数独無料 / ナンプレ”与品牌入口。
- /play/：免费问题集、按难度选择；不是第二个同名首页。
- /play/{level}/：明确难度的在线游戏。
- /guide/{difficulty}/：该难度的解法；/guide/tips/负责技术总览；具体手筋只归对应技巧页。
- /print/及难度打印页：PDF、印刷、答案等纸面任务；/print/senior/负责大字/活动用途。
- /tools/solver/：用户持有题目的解析与答案；新闻页保留具体输入说明，不冒充报纸官方今日答案。

一个查询出现多个URL可能只是多种意图或正常多结果展示。没有周级URL替换、点击下降与意图等进一步证据，不合并页面、不做大规模重定向、不切换canonical。

## 后续运营，不再以开发工单替代

1. 关键词经营：维护owner和目标查询组；每次以最新成熟完整7天，对比前7天及前4周同星期，分日本/设备/搜索引擎看数据。GSC缺失日期不补零。不按每天波动反复改标题；至少有两个成熟完整周后再判断本组方向，并承认样本与季节性限制。
2. 排名推进：优先这些有曝光的4—20位查询；发现实质内容缺口才补解答/例题。进入前列且有点击的内容做相关内链扩展；无需求或竞品指名的词不铺页。
3. 市场扩张：用竞品缺词与其真实搜索落地页找我们尚未进入的日本需求。Semrush 10/4入口跳到登录，已停止访问并关闭浏览器；当前没有新竞品流量、搜索量或SERP数据。Bing关键词凭据配置仍不可用，GA4的Bing会话不能替代关键词排名。此两项为具体证据缺口，不据此编造机会规模。
4. 外部推荐：四份日文申请已准备，详见[渠道原稿](../../growth/2026-10-04-japan/distribution.md)。按实际推荐页、相关性、采用和来访跟踪；本轮未获明确发送授权，未代发。推荐材料的数量不能算外链数。
5. 搜索引擎反馈：继续保留索引、抓取、重定向和站点地图监测；前次已核验的正常索引不反复提交当工作成果。暂不进行没有证据的全站技术重构。

运营复盘只回答：本期目标词是什么、哪些内容/内链/外部动作实际执行、获得多少新增自然访问、哪些假设失败、下一投入依据是什么。资料整理量、文章量、题目量和发送量均不代替获客结果。
