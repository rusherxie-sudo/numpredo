## 投入决策

1. 保留已经增长的中级、超难问和打印入口，停止没有明确获客假设的新增功能。下一轮站内工作应服务于明确词组的竞争条件，不再扩小变体、无差异文章或PDF数量。
2. 经营两个层次：中级/初级等已有曝光词争取前列；通用免费数独/ナンプレ词扩大有效覆盖。不能只在本站已有曝光里优化CTR并承诺量级跃升，也不把GSC偶尔出现的低样本平均名次当稳定排名。
3. 问题集目录实验未证明有效，不把其上线算成功；需同词/设备、展示URL与实际SERP进一步复核后才决定调整，不立刻盲目回滚。
4. 站外推荐尚未形成渠道：10/4四份材料仍为待发送，未确认采用。应以真实审核/采用/引荐为执行成果；新增文案或嵌入组件不算渠道增长。本轮没有对外发送授权，没有代发。
5. 周复盘以新增用户、自然落地会话和目标词净点击为准；把增长页与损失页同时列出。不能用14天改善否认最新一周停滞。
