## 资源规模与生产方式

[6×6打印](https://numpredo.com/print/6x6/)为问题三页、答案三页，每张A4两题；[不等号打印](https://numpredo.com/print/inequality/)为问题六页、答案六页，每张一题；[16×16打印](https://numpredo.com/print/16x16/)为问题四页、答案四页，每张一题。共十六题、六个PDF，问题与答案各十三页。

6×6及不等号打印与在线版共用题源，不能重复计算成新增二十八道独立题。16×16采用固定随机种子生成不同盘面、解答与挖空位置，空格数为80、88、96、104；定位为入门练习，不以空格数虚构专业难度。它是小规模种子资源，尚不等于大批量成熟题库。

生产命令为npm run gen:variant-packs，依次输出稳定问题ID与题源清单，再生成独立问题/答案PDF。生成器与校验进入仓库；题库清单和PDF均已提交，线上构建无需安装PDF生成依赖。PDF生产需要Python、ReportLab及日文字体，现有生成环境已验证。
