## 新增用户价值

现有题库筛选已能按手筋选整题，三个教程各有两道实际作答练习；/practice/原来是五道手筋名称诊断。新功能是同一/practice/页面内的“次の一手・5問チャレンジ”：选择一种手筋，直接回答指定格应填入或消去的数字，不把既有筛选重新叫作新功能。

- 9种手筋各5个真实局面，共45局面：裸单、隐单、区块排除、裸对、隐对、裸三数组、摩天楼、X-Wing、Swordfish。
- 每个局面来自现有标准题库，在该题最难手筋的第一次实际应用处截取。保留此前所有候选消去，能核对原难度、题号和步骤。
- 一局5问，顺序随机；按首次回答计分，提供根拠提示、具体推理、正确操作和教程/原题链接。不是每日新增题目或能力评级。
- 错题可以单独复练；每种手筋独立保存本轮顺序、位置、已答数字、提示状态和结果；恢复不重复记为新完成。保存关闭/损坏/旧题ID时安全降级或重开。
- 九篇教程的实战集合直接连接指定手筋挑战；技巧总览更新已有练习入口。既有五题诊断继续可用。

## 数据与实现边界

标准题总数仍4,395；45是从既有题目截取的局面数量，不是45道新原创完整数独。不新增索引HTML页面，Sitemap仍68个入口。挑战使用普通/practice/ canonical，tech参数只选择玩法。

构建前由scripts/gen-one-move.ts从现有公开题库分析与逻辑引擎确定性生成9份静态JSON，合计45,546字节（约44.5KiB；文件系统占用约72KB）；仅在用户点击开始时获取选中的一份。浏览器不加载完整题库或求解引擎。新增生成校验包括唯一解、局面已填数字与原解一致、所有未填格保留真解候选、正确填入/消去不破坏真解；错选项由原手筋步骤排除已消去候选，问题描述明确限定“这个手筋/这组根拠”。

进度仅存同一浏览器本地，不支持跨设备账号同步；清除浏览器数据会丢失。重新挑战仅改变同5题顺序。静态数据公开包含答案，本产品是学习练习而非竞赛防作弊系统。

## 衡量

单独事件：one_move_start、one_move_resume、one_move_hint、one_move_answer、one_move_complete。参数包括technique、mode（challenge/review），作答含question_id/correct/hint_used，完成含correct_count/question_count。不写入source/medium/campaign，不把一手练习混入完整数独game_complete。

开始/恢复/完成均代表浏览器操作，不能按事件次数直接推算独立用户留存或学习成效。新增参数尚未注册GA自定义维度；基本事件名可先查，细分报告另确认可用性。发布前测试阻止统计网络发送，尚无生产真实使用或获客增量。

优先看：练习启动用户、包含完成挑战的会话、错题复练使用、从练习进入原题的实际使用；按同渠道、国家、完整周窗口观察，不把教程流量上涨自动归因为新功能。无新自动任务、无站外发送。
