# 日本市场：竞争、获客与本轮执行

核验日：2026-10-04。范围仅日本。本文是执行记录和获客材料，不是增长已实现的声明。

## 1. 大增长的约束与选择

GA4（日本时区）09-27—10-03总会话3,392，约485/日；自然搜索2,780，占82%。GSC最终Web数据09-23—29为1,027点击、32,298曝光、CTR3.18%。两个窗口不同，不混为渠道漏斗。

仅把现有GSC曝光的CTR提高到5%，数学上约增加84次搜索点击/日；并不能把约500日会话变成5,000。要争取成倍增长，必须同时扩大日本主流查询的有效覆盖、建立站外获客、形成回访。5,000/日为审视投入量级的愿景，不是预测或承诺。

当前站内供给已经超过获客能力：4,395题、每日7题、五档玩法、解法和打印均已存在。过去把“又做了一份PDF/一个小组件”当作渠道拓展，没有采用证据。这次把已有题库完整开放为主产品，并准备可以实际送审的渠道材料。站外采用仍是未完成的业务环节，不能由开发完成替代。

## 3. 当前公开竞品观察

10/4浏览器只读访问，不是流量估算。

- [ナンプレ7](https://numpre7.com/)：首页直接突出“毎日7問”、七档难度、保存和书签，站内显示累积25,536题、各档平均时间；提供AI解答和系统手筋入口。这些是页面展示，不代表已独立验证其题量或平均时间统计。启示是明确的长期使用理由和大题库承接，本站不应继续把4,395题藏在随机打印功能里。
- [Sudoku.com日文版](https://sudoku.com/jp)：六档、每日挑战、奖项、活动/竞赛入口，游戏优先，提示文案明确包含解法说明。不能宣称本站“有解说”就有独有优势。`/ja`返回404，正式日本页面为`/jp`。
- [sudokuhit](https://sudokuhit.com/)与[sudoku-freeplay](https://sudoku-freeplay.com/)根路径本次显示英文；可观察游戏操作，但不把英文根页当日本搜索落地或日文竞争证据。

竞争选择：围绕“按具体手筋选题、逐题保留进度、从解法学会并接着玩”建立可核验的产品理由，完整承接中级/上级/难题需求。还不能证明这是日本市场独占功能或已形成品牌偏好。

## 4. 本轮可复核的实施

- 五档完整题库：初级/中级/上级/超难问各1,000题，难问395题。原序号与题面保持不变，新增的是在线可选择范围，不是新创作3,945题。
- 每档支持手筋、进度筛选、编号直达、未完成选题；分题保存，多题切换后可返回续玩。兼容原单槽进度，不伪造历史通关记录。
- 九种手筋教程接入对应实战题目；每个推荐来自实际引擎路径，手数/提示数能用公开CSV复核。XY-Wing没有对应题库标签，不制作虚假集合。
- 单题链接和完成分享保留准确题号；参数页canonical仍指向原难度页。保持68个索引入口，没有创建4,395个编号SEO页面。
- 题库选择逻辑接近可视区才加载，保留原首屏脚本体积预算；全量检查唯一解、逻辑完答和所有筛选标签。
- 站外送审包见[日文渠道材料](distribution.md)和[候选表](prospects.csv)。未发送，没有合作/采用的确认。

## 5. 验收：把流量增量和产品使用分开

发布前基线：GA4总会话3,392/周、有机2,780/周；GSC独立窗口1,027点击/周。发布后使用完整且已成熟的同星期窗口，并同时看日序列；不要拿不完整当天对完整上周。GSC数据未到达的日期不填零。

1. 主指标：日本总会话、自然会话、Google/Bing/Yahoo拆分；五档游戏页和教程的非品牌查询点击及曝光。先看新增入口用户，再看全站是否增加，避免把站内跳转当新获客。
2. 使用验证：library_select / library_filter / puzzle_link_copy、game_complete；事件数不是新增访客。GA跨日活跃/回访人数以用户口径计算，不与渠道人数相加。页面内选题不是新的page_view，不人为增加会话。
3. 分发：prospects.csv保留准备、已发送、已采用、推荐URL四个独立事实；若合作方接受参数，使用提供的来源链接，否则以真实referrer核对。本站内部导航不加UTM。外部采用者的页面曝光不算本站访问。
4. 加码条件：搜索曝光和新增会话持续同向上升，并出现实际练习/完成；站外渠道出现经核对的采用及有效引荐。未使用的功能不继续复制；仅有索引无曝光时，回到需求/竞争/渠道判断。
5. 不能宣布增长：仅构建成功、功能使用增加、参数导致来源重新分类、某一天反弹、未成熟GSC空白，均不算达成大增长。

最高优先级的剩余动作是让已准备的日本渠道材料真正进入对方审核，再按采用数据扩展同类渠道。对外发送需要用户明确指令（会话的工具通信权限要求），本轮不代发、不填入未经确认的个人身份、不扩大内容转载授权。无需再开发一个分发小工具才开始送审。
