## 证据与内容分工

依据2026-10-06—11-02日本GSC Web/final及11/5竞品页面观察。4×4打印、候选笔记、隐藏三数组存在少量本站查询曝光；其他专题来自独立规则/教学任务和竞品覆盖缺口，属于需求探索，不宣称已有搜索量。Killer专家、高龄者打印等已有承接页保留原URL，不重复建近义词页。

- 专题：六种新增技巧用标注为局部说明图的候选模型，验证所有满足前提的赋值及放宽条件的反例；不冒称游戏引擎已支持这些技巧。其余专题使用完整原题局面或明确条件的45法则计算。
- 打印：76道选题，复用已验证题库；4×4、Killer、对角线、候选笔记及六种技巧专项。20份A4问题/答案PDF与20张实际PDF预览。技巧集8题各有来源和实际消去依据；区别于原/print/techniques/的简短样题总览。
- 实战：八道固定原题，按不同关键手筋分别编写方针、误区、复盘；包含真实卡点候选图和完整解答记录。题号固定在selections.json，不随练习随机选题改变。
- 内链：guide和print目录、旧技巧页、实战总览及上下文关联；每个索引页至少两个其他页面主内容链接，继续使用原45%正文相似度门槛。
