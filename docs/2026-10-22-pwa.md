# 在线 PWA 与回访实验

2026-10-22。用户批准安装功能，并明确不需要离线游戏。本次目标是方便已有玩家返回，不将安装量等同 SEO 新增流量。

## 实现

- 全站提供日文 manifest、192/512 图标、独立 maskable 图标、Apple 图标。启动页 `/play/`，沿用 canonical，不加获客 UTM。图标由现有 favicon 生成：`node scripts/gen-pwa-icons.ts`。
- **无 Service Worker、离线预缓存、推送或账号系统**。仍需联网，现有游戏存档不改结构。不同浏览器/设备不承诺同步。
- 支持原生安装事件时调用系统窗口；iPhone/iPad 提供添加到主屏幕步骤。页脚提供主动入口；不支持的环境不展示无效按钮。安装后独立窗口访问 `/play/` 时，可返回本浏览器最近玩的标准难度。
- 仅有标准数独组件的页面主动提示（含标准游戏、daily、Killer/对角线）。首次访问不主动展示；两次访问（以30分钟无操作为分隔）或累计完成两局后才符合资格。提示在盘面后，不覆盖键盘。尚未接入完成事件的小变体不按完成局数触发。
- 符合资格且可安装的浏览器随机固定为提示/对照组，各50%。对照组仍可从页脚或浏览器菜单自行安装，实验衡量主动引导的增量。
- 展示后7天不再主动展示；关闭或处理系统窗口后30天不再主动展示。存储不可用时不主动提示；已安装/独立窗口隐藏提示。
- 轻量捕获器先接住安装事件，完整引导延后1.5秒加载。内容页只允许这一个≤2KiB的捕获器例外，全站64KiB首屏脚本上限仍保留。

## 统计与判断

| 事件 | 含义 |
| --- | --- |
| `pwa_enrolled_prompt/control` | 首次满足实验资格、随机分组；分母按用户去重 |
| `pwa_prompt_view` | 提示至少一半进入视口，不把隐藏DOM计为曝光 |
| `pwa_install_open/click/help/choice` | 主动打开、点击、iOS说明、系统选择；均不等于安装成功 |
| `pwa_installed` | 浏览器 `appinstalled` 通知；iOS说明不计入 |
| `pwa_launch` | 独立窗口页面进入，同标签页30分钟内导航/刷新去重；不代表系统层面的每次唤醒 |
| `pwa_cohort_visit` | 实验用户每次访问，携带相对入组日龄 |
| `pwa_return_7d_prompt/control` | 入组后第7–13日回访，浏览器仅记一次 |
| `pwa_return_28d_prompt/control` | 入组后第28–34日回访，浏览器仅记一次 |
| `pwa_game_complete` | 标准组件完成游戏，辅助观察实际使用 |

以上7日/28日事件是固定周窗口回访，**不是精确第7/28日留存**。对比已完整经历观察窗口的同期入组用户，不把滚动全部入组人数作分母。按用户数看组间回访差异、样本量与不确定性，同时检查是否降低游戏完成；安装者与未安装者直接比较不能证明因果。首批完整周窗口最早11月5日、28日窗口最早11月26日成熟，实际以各用户入组时间为准。

事件自带 `pwa_group`、`display_mode` 等参数，但未修改GA4账户自定义维度。基本分组入组/回访使用独立事件名可查询；细分参数若需要在报表使用，再登记自定义维度。客户端排队已验证，GA服务端采集及真实效果须发布后复核。没有设置自动监控任务。

边界：统计按浏览器识别；清除存储会重置分组，iOS主屏幕与Safari可能使用分离存储，广告拦截也会造成漏记。iOS跨容器回访不能可靠串联，不能宣称严格的跨端留存率。没有注册任何指纹或自建用户ID。

## 验证

- 类型检查、构建、SEO/内容/全题库检查通过，68个索引入口不变。
- Chromium原生manifest检查无错误，常规浏览器上下文安装资格检查无错误；隔离上下文仅提示无痕模式限制。
- 浏览器验证：首次不主动提示；第二次访问/完成两局资格；对照组不主动提示、仍可主动安装；关闭30日持久化；系统接受不等于安装完成；`appinstalled`事件处理（模拟完成通知）；独立模式隐藏提示和续玩入口；启动/回访去重；禁止存储降级；无Service Worker和Cache Storage；填数刷新仍保存。
- 390px手机布局无横向溢出，iPhone UA及触控环境的说明/事件通过。系统安装对话框以模拟事件测试，尚未在实体Android/iPhone完成系统级安装验收；不把模拟检查写成真机安装成功。
