## 二、独立评估发现（按收益 × 风险排序）

### P0 问题（技术，最该今天动）

**三个 8/26 上线页面 10 天仍未收录，且从未被抓取。**
- `/guide/number-place/`、`/guide/sudoku-algorithm/`、`/print/blank/`
- URL Inspection 均返回 `coverageState = "Discovered - currently not indexed"`，`pageFetchState = UNSPECIFIED`（从未 fetch）、`lastCrawlTime = null`。
- 三者线上均 HTTP 200、在 sitemap-0.xml（62 URL 全带 lastmod）、robots.txt 放行、各有内链 —— **无技术硬阻，纯 crawl 优先级被降**。
- 内链强度对比：`/guide/sudoku-algorithm/` 有 solver 页正文链；`/print/blank/` 在全局导航 + /print/ ×2 + /tools/generator/；`/guide/number-place/` 最弱，仅 1 条 FAQ 答案上下文链 + 低流量 guide index。
- 对照：9/3 上线的 `/variants/4x4/` 两天即被抓取并收录（verdict PASS，lastCrawl 9/4），说明**不是全站 crawl 停摆，而是这 3 页被单独降权**。
